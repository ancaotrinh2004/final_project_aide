# Đây là file bao gồm tất cả các yêu cầu để bạn viết docs và readme cho project này

## README.md 
Đây sẽ là file viết hướng dẫn chạy overview project. 
Ở file này sẽ bao gồm các mục sau: 
- Table of contents 
- Architechture
- Prerequisites
- Quick Start
- Data model  

Ở mục `Quick Start` này sẽ hướng dẫn tổng quát cho người khác đọc vào có thể setup project này từ đầu tới cuối. Phần này phải viết cực kì chi tiết như setup cluster, deploy các component lên cluster như thế nào (Khuyến khích bạn nên viết sao cho người đọc setup theo như thự tự best practice bên ngoài). Với mỗi mục deploy component bạn không cần viết chi tiết cài những gì mà bạn chỉ cần links tới file setup component đó trong folder @docs. 

Phần data model sẽ dán ảnh diagram để trong folder @docs/assets vào.

Phần architecture bạn cứ để đường dẫn tới ảnh là @docs/assets/architecture.svg (Tôi sẽ update ảnh vào sau).

## Docs
Về phần setup các component. Bạn nên viết chi tiết theo như những gì chúng ta đã setup trong project này. Và hãy lấy những screenshot mà tôi đã để trong folder @docs/assets thêm vào.
Riêng phần file jenkins-setup.md hãy giữa nguyên.

## Phong cách viết 
Bạn hãy tham khảo các project được nhiều star trên github và trình bày bám sát theo những project đó.
